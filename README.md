# internet-speed-meter

Скрипт замеряет скорость интернета с вашего компьютера. Он принимает адрес тяжёлого файла
(например, большой картинки), последовательно выполняет 10 запросов, каждый раз скачивает
ответ целиком и печатает среднее время запроса, объём скачанных данных и скорость в Мбит/с
и МБ/с.

Зависимостей нет, только стандартная библиотека Python.

## Требования

Python 3.10 или новее. Проверить версию: `python3 --version`.

Команда запуска Python зависит от системы: на Linux и macOS обычно `python3`, на Windows
`python` или `py`. Ниже везде написано `python3`, подставьте свою.

## Установка и запуск

```bash
git clone https://github.com/r-1805/internet-speed-meter.git
cd internet-speed-meter
python3 speed_meter.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Другой адрес для проверки: тестовый файл Cloudflare на 25 МБ. Кавычки нужны из-за `?` в адресе.

```bash
python3 speed_meter.py "https://speed.cloudflare.com/__down?bytes=25000000"
```

### Какую ссылку взять

Подходит любая ссылка `http://` или `https://` на файл: картинку, видео, архив. Главное:

- Ссылка должна вести на сам файл, а не на страницу, где он показан. Прямую ссылку на картинку
  можно получить через правый клик → «Копировать адрес изображения»: если открыть её
  в браузере, будет только картинка.
  - файл: `https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg`
  - страница: `https://commons.wikimedia.org/wiki/File:Fronalpstock_big.jpg` (скрипт скачает
    HTML на 141 КБ и предупредит, что это, возможно, не файл)
- Файл должен быть тяжёлым, лучше от 10 МБ. Картинки с сайтов и мемы часто весят сотни
  килобайт: на таком объёме время уходит в основном на установку соединения, и скорость
  получается неточной. Если ответ меньше 1 МБ, скрипт об этом предупредит.
- Некоторые сайты не отдают файлы скриптам и отвечают `HTTP 403`, а при частых повторных
  замерах могут ответить `HTTP 429`. В этом случае возьмите другой адрес или подождите
  несколько минут.

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | — | Адрес файла, `http://` или `https://`. Кириллица и пробелы кодируются автоматически |
| `-n`, `--requests` | `10` | Сколько запросов выполнить |
| `-t`, `--timeout` | `30` | Сколько секунд ждать данных от сервера |
| `--json` | выключен | Вывести результат в JSON |

### Коды выхода

| Код | Значение |
|---|---|
| `0` | Хотя бы один запрос успешен |
| `1` | Ни один запрос не выполнился |
| `2` | Неверные аргументы |
| `130` | Прервано через Ctrl+C |
| `141` | Получатель вывода закрылся раньше времени, например `\| head -3` |

## Как считаются метрики

Каждый запрос состоит из двух частей: ожидания ответа (DNS, TCP/TLS, редиректы, обработка на
сервере) и скачивания тела.

- **Время запроса** — обе части вместе, от начала запроса до последнего байта.
- **До первого байта** — через сколько пришли заголовки ответа.
- **Скорость скачивания** — байты, делённые на время скачивания тела. Основная метрика: не
  зависит от задержки сервера перед ответом.
- **С учётом ожидания ответа** — байты, делённые на полное время запроса. Ниже первой и
  сильнее зависит от размера файла. В одном из замеров на файле 5 МБ получилось 88 Мбит/с
  против 159 Мбит/с скорости скачивания.

Итоговые скорости считаются как сумма байтов, делённая на сумму времени успешных запросов,
а не как среднее скоростей: один случайно быстрый запрос завысил бы среднее.

1 МБ = 1 000 000 байт, 1 МБ/с = 8 Мбит/с.

С `--json` выводятся все запросы, итог и предупреждения: время в секундах, размер в байтах,
скорость в Мбит/с. Если ни один запрос не прошёл, метрики итога равны `null`, а не `0`.

## Ошибки

Неудачный запрос не останавливает замер: скрипт пишет причину, переходит к следующему
и не учитывает неудачный в средних. Повторных попыток нет, чтобы нестабильное соединение
не выглядело стабильным.

```
[1/2]  ОШИБКА: HTTP 404 Not Found (через 0.457 с)
```

| Сообщение | Что делать |
|---|---|
| `HTTP 403` | Сайт не отдаёт файл скриптам: взять другой адрес |
| `HTTP 404` | Файла нет по этой ссылке: проверить адрес |
| `HTTP 429` | Сервер ограничил частые скачивания: подождать несколько минут или сменить адрес |
| `не удалось найти хост (DNS)` | Проверить домен и подключение к интернету |
| `тайм-аут` | Увеличить `-t`, проверить прокси и файрвол |
| `сервер закрыл соединение…`, `соединение оборвалось…` | Повторить замер, при повторении сменить адрес |
| `не прошла проверка SSL-сертификата` | На macOS с Python с python.org запустить `Install Certificates.command` из папки Python |

Если ответ в среднем меньше 1 МБ, скрипт предупреждает, что результат неточный. Так бывает,
когда адрес ведёт на HTML-страницу, а не на сам файл.

Прокси из переменных `HTTP_PROXY` и `HTTPS_PROXY` учитываются автоматически.

## Ограничения

- Скорость меряется до конкретного сервера. На одном канале Wikimedia дала 92 Мбит/с,
  а Cloudflare 332 Мбит/с. Для оценки канала сравните несколько серверов.
- Каждый запрос открывает новое соединение, чтобы все 10 запросов измерялись одинаково.
- Тайм-аут действует на каждую операцию чтения, а не на весь запрос: медленная, но
  непрерывная отдача не прерывается.

## Как использовался AI

Код написан с Claude Code. Результат проверялся тестами, прогонами на реальных серверах и
отдельным ревью. Исправления видны в истории коммитов, главные из них:

- **Неверная метрика.** Скорость считалась по полному времени запроса, включая ожидание
  ответа сервера, поэтому занижалась и зависела от размера файла.
- **Молча искажённые данные.** Обрезанный ответ засчитывался как успешный: `http.client` при
  чтении кусками не сообщает об обрыве. Ответ на 1 КБ выдавался как нормальный замер.
- **Падения.** URL с кириллицей, вывод в файл на Windows с кодировкой cp1252 и `| head`
  заканчивались трейсбеком. Ctrl+C терял уже сделанные замеры.
- **Ошибка в обработчике ошибок.** Он сам падал на `SSLError` без атрибута `reason`. Теперь
  тест прогоняет через него все подклассы сетевых исключений.
- **Код «на всякий случай».** Заголовки `no-cache` не влияли на ответ CDN и были убраны.
  `urlopen` на каждый запрос заново загружал SSL-сертификаты (~5 мс внутри замера), теперь
  контекст один.
